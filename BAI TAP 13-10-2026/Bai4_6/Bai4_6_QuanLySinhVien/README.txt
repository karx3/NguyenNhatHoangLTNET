BAI 4.6 - QUAN LY SINH VIEN

Project WinForms .NET Framework 4.7.2.

Mo project:
1. Giai nen file ZIP.
2. Mo Bai4_6.csproj bang Visual Studio.
3. Neu may chua co .NET Framework 4.7.2 Developer Pack, cai dat hoac doi TargetFrameworkVersion trong project sang framework da cai.
4. Bam F5 de chay.

Chuc nang:
- BindingSource ket noi BindingList<Student> voi DataGridView va cac control nhap lieu.
- Them, xoa, cap nhat sinh vien.
- Chon avatar JPG/JPEG/PNG/BMP.
- Tu dong doi avatar khi chon dong sinh vien khac.
- Xuat danh sach CSV ma hoa UTF-8 co BOM.

Luu y:
- Duong dan avatar duoc ghi vao CSV; file anh khong duoc nhung vao CSV.
- CSV co cac cot StudentId, FullName, Age, Gender, AvatarPath.
